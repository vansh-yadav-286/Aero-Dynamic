# Security Policy

## Supported Versions

Currently, only the `main` branch (latest release) is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Aero Dynamic, please report it to us as described below.

**Please report security issues directly to the maintainers via email or through the GitHub Security Advisory feature (if enabled on the repository).**

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, or have not heard from us for the past 5 days, please follow up with us.
